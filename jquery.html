jQuery

Una biblioteca de JavaScript que facilita el desarrollo de páginas web interactivas.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para simplificar algunas tareas frecuentes del desarrollo web.

Permite seleccionar elementos HTML, manejar eventos y crear efectos de una manera sencilla.

Sintaxis básica

Una de las características principales de jQuery es el uso del símbolo $. 


$("#mensaje").hide();

$("#mensaje").show();

Ventajas y desventajas

Ventajas

  • Sintaxis sencilla.
  • Facilita algunas tareas.
  • Permite crear efectos fácilmente.

Desventajas

  • Necesita una biblioteca externa.
  • JavaScript moderno ya ofrece muchas alternativas.
  • No siempre es necesario en proyectos nuevos.
