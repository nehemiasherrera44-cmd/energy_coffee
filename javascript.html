TECNOLOGÍA WEB

JavaScript

El lenguaje que permite agregar comportamiento e interacción a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite que una página pueda responder a las acciones realizadas por el usuario.

HTML, CSS y JavaScript

HTML

Se encarga de la estructura de una página web.

CSS

Se encarga del diseño, colores, tamaños y estilos.

JavaScript

Se encarga del comportamiento y la interacción.

Conceptos básicos

Variables

Permiten guardar información que puede utilizar el programa.

Funciones

Son bloques de código que realizan una tarea determinada.

Eventos

Permiten reaccionar a acciones como hacer clic o pasar el mouse.
